# CMOS Analog IC Design Projects

A portfolio of analog IC design projects designed in **Cadence Virtuoso** using the **gm/ID methodology**.

---

## Projects

| # | Project | Description |
|---|---------|-------------|
| 1 | [Two-Stage Miller OTA](./01-Two-Stage-Miller-OTA) | Two-stage Miller-compensated OTA with RHP zero cancellation |
| 2 | [Fully Differential Folded-Cascode OTA](./02-Fully-Differential-Folded-Cascode-OTA) | Fully differential folded-cascode OTA with capacitive feedback and CMFB |
| 3 | [Self-Biased Sub-1V BGR](./03-Self-Biased-Sub-1V-BGR) | Self-biased sub-1V bandgap reference with startup circuit |
| 4 | [Rail-to-Rail Input Translinear-Loop Class-AB](./04-Rail-to-Rail-Input-Translinear-Loop-Class-AB) | Rail-to-rail input op-amp with Class-AB output stage |

---

## Tools Used
- **Cadence Virtuoso** — Schematic entry and simulation
- **ADT (Analog Design Tool)** — gm/ID-based transistor sizing

## Skills Demonstrated
- gm/ID design methodology
- Analog IC design (OTAs, BGR, Class-AB)
- Frequency compensation
- Common-mode feedback (CMFB)
- Stability analysis (STB)
- Bandgap reference design
- Class-AB output stage design
